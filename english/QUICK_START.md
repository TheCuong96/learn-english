# 🚀 Quick Start - Chạy ứng dụng ngay!

## ⚡ 3 bước đơn giản:

### 1️⃣ Cài đặt (chỉ cần làm 1 lần)
```bash
cd english
npm install
```

### 2️⃣ Chạy server
```bash
npm run dev
```

### 3️⃣ Mở trình duyệt
Truy cập: **http://localhost:3000**

---

## 📱 Các trang có sẵn:

### 🏠 Trang chủ - http://localhost:3000
- 📚 Học với thẻ ghi nhớ
- ✅ Bài tập trắc nghiệm
- ✏️ Điền vào chỗ trống
- 🔄 Chia động từ

### 🔊 Verbs Audio - http://localhost:3000/verbs-audio
- Xem tất cả 804 động từ
- Phát âm V1, V2, V3
- Tìm kiếm nhanh
- Màu sắc trực quan

---

## ❓ Lỗi thường gặp:

### Port 3000 đã được sử dụng?
```bash
npm run dev -- -p 3001
# Sau đó truy cập: http://localhost:3001
```

### Chưa cài Node.js?
Tải tại: https://nodejs.org (chọn LTS version)
